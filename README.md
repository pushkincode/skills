# PushkinCode Skills

Навыки для работы с проектами: `spec` помогает подготовить спецификацию и дорожную карту, `how` — разобраться в устройстве проекта.

## Установка

Нужны Node.js 18 или новее, npm, Git и доступ к GitHub. Откройте терминал в папке проекта и выполните:

```bash
npx github:pushkincode/skills
```

Выберите своего агента. Установщик добавит все навыки в текущий проект. В Codex можно вызвать `$spec` и `$how`, в Claude Code — `/spec` и `/how`, в Kimi Code CLI — `/skill:spec` и `/skill:how`. Если навыки не появились, начните новую сессию.

Чтобы обновить навыки, повторите команду и выберите тех же агентов. Установщик остановится, если обнаружит чужой скилл с таким же именем или локально изменённый файл; он не перезапишет его. `.pushkincode-skills.json` хранит сведения об установленных файлах и нужен для безопасного обновления.

Для неинтерактивной установки можно указать `--agent codex`, `--agent claude`, `--agent kimi`, `--agent opencode` или `--agent all`. Точный синтаксис передачи параметра через npm зависит от команды запуска; проверьте его в своей среде.

Установщик работает в папке, из которой запущен. Доступность отдельных функций навыков зависит от возможностей агента и модели.
