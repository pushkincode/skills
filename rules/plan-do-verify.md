# Plan → Do → Verify

Every task has three steps. Don't skip them.

**1. PLAN** — before doing:
- Understand the task by reading the relevant code and context.
- Define verification criteria: how will you know it's done right?
- For a large task, ask necessary clarifying questions and share a plan.

**2. DO** — work by the plan:
- Follow the plan; don't wander off.
- If a problem appears midway, return to step 1.

**3. VERIFY** — before saying "done":
- Check the result against the criteria from step 1.
- State what you checked.
- No verification means the task is not done.

If verification fails, diagnose the cause, adjust the plan, and retry. After
three unsuccessful iterations, stop and ask the user for direction.

Scale the process to the task:
- Large task: full process and a plan shared with the user.
- Medium task: an internal plan and mandatory verification.
- Small task: verification only.

When in doubt, choose the more thorough mode.
