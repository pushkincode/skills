# Обработка ошибок

- Проверяй ошибки и граничные случаи в начале функции с помощью guard clauses.
- Используй ранний `return` для веток с ошибками; избегай глубокой вложенности
  `if`.
- Оставляй основной успешный путь в конце функции для удобства чтения.
- Не проглатывай ошибки. Возвращай или пробрасывай их вызывающему коду.
- Логируй ошибку на границе системы, где она обрабатывается. Не логируй одну и
  ту же ошибку повторно на каждом уровне.
